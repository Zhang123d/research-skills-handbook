# 第二篇 · ECC：工程开发与 Agent 工作流

[返回全书目录](../../README.md) · [使用方法](../getting-started.md)

本篇统一管理 **ECC 2.2.3 的 348 个入口**，包括 311 个常规技能和 37 个迁移命令技能。先按任务进入一章，再查看具体技能。用途分章是本手册的导航方式，并未修改 ECC 的实际安装结构。

## 安装与依赖

来源：[ECC](https://github.com/affaan-m/ECC)。本机插件版本为 2.2.3。此处只管理其主要技能目录与迁移命令目录，不把随包的翻译、其他宿主示例和缓存重复计为新技能。
不同技能可能需要对应框架、CLI、MCP 或账号；带有可调用入口不代表工具和外部服务已经准备好。
